# Anti-Jamming-Matlab

MATLAB simulations of jamming and anti-jamming in DRL-based channel selection for LEO non-terrestrial networks.

| Folder | Contents |
|---|---|
| [`ADJ/after/`](ADJ/after/) | **Current code.** Advanced Persistent Jamming (APJ) against DQN-based channel selection. Start with its README. |
| `legacy/` | Earlier prototypes kept for reference only (behaviour-cloning APJ, hybrid-reward DQN sample, frequency-hopping samples). Not maintained. |
